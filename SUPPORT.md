# Support

If you run into a problem with SFTP Uploader, please open an issue at:

https://github.com/huangshiyu13/vscode-sftp/issues

When reporting a bug, it helps to include:

- your VS Code version
- your extension version
- the relevant part of `.vscode/sftp.json`, with secrets redacted
- whether you are using FTP, SFTP, `hop`, or OpenSSH `ProxyJump`
- the SFTP output log with hostnames, usernames, tokens, and paths sanitized

Before opening a new issue, also check:

- [README.md](./README.md)
- [FAQ.md](./FAQ.md)
