# SFTP Uploader v0.1.1

This release focuses on stability, maintainability, and release hygiene for the maintained fork.

## Highlights

- Added CI workflows for linting, compile checks, unit tests, and coverage uploads
- Added Codecov integration and repository coverage rules
- Expanded automated coverage to more than 50% for both statements and lines
- Improved `Upload Changed Files` handling for ignored files and SCM-driven uploads
- Reloaded `.vscode/sftp.json` automatically when config changes outside the editor
- Masked nested sensitive fields in hop and `proxyJump` configuration logs
- Added regression tests for transfer, watcher, command, config, and remote connection behavior

## Quality improvements

- `npm run verify` now runs lint, compile, and coverage checks together
- Added contribution guidance for testing, coverage, privacy-safe fixtures, and release workflow
- Added repeatable `make` targets for verify, package, tag, GitHub release, and Marketplace publish
